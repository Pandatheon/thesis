\chapter*{Abstract}
\label{Chapter::Abstract}
{
    % Override language formatting for English abstract
    % Add paragraph indent as English paragraphs must be indented
    \setlength{\parindent}{2em}
    % Remove paragraph spacing as required in the English language
    \setlength{\parskip}{0em}

    In nonlinear model predictive control, sequential quadratic programming (SQP) with the exact Hessian of the Lagrangian
    produces quadratic programs (QPs) whose Hessian can be indefinite.
    Structure-exploiting QP solvers require a positive definite Hessian,
    so the Hessian is usually regularized before it is passed to the solver, which changes the solution of the QP.
    This thesis instead handles the indefiniteness inside a primal--dual interior point solver,
    where the barrier term already adds curvature on the constraints and only the reduced Hessian has to be positive definite.

    We propose a primal regularization inside the Riccati recursion
    that corrects the Hessian only at the stages where the factorization detects negative curvature,
    so the cost stays linear in the horizon length.
    We show that the minimum perturbation correction can make the preceding stages indefinite and ill-conditioned,
    derive an improved strategy that also regularizes the cost-to-go matrix,
    and prove that the regularization becomes inactive near the solution.
    The methods are evaluated on a benchmark of $175$ indefinite QPs collected from the SQP iterations of eight optimal control problems.
}
